Harvest Evening

Original Hearth environment artwork, created for this project with the built-in
image generation tool. No third-party reference images or artwork were used.
The complete generation prompt is in prompt.txt beside these sources.

00-patch.svg embeds the original PNG painting losslessly, using the same
self-contained raster-in-SVG source format as Open Bay. It renders offline
through scripts/render-theme.sh; no generation service is needed to rebuild.
The painting is uniformly scaled and cropped by less than one source pixel
to fill the 16:9 canvas, then rendered to the 1920x1080 base.

Three prominent carved pumpkins sit above the favorites row, with smaller
pumpkins and vines receding into a moonlit field. Amber candlelight and copper
skin contrast with deep ink-blue and petrol shadows. The upper corners and
lower foreground remain naturally dark for Home lettering and controls.
No text, logos, characters, personal details or UI are baked into the image.

The painting and candlelight stay still. 01-mist.svg adds a faint, feathered
half-resolution valley mist. It wraps at 16 dp per minute through the existing
drift renderer, with transparent edges. No flashing, flickering or intro event.
Reduce motion preserves the whole scene at rest; backgrounding stops motion
through the shared lifecycle. Layers decode to about 8.3 MiB, below 32 MB.

Build offline with scripts/render-theme.sh harvest-evening using Chrome and
a Python interpreter with Pillow and numpy. The base uses the existing
lossless WebP and anti-banding grain pipeline; the mist preserves alpha.

The stable harvest-evening id preserves existing assignments. This seasonal
pack remains excluded from implicit rotation, with no default dayparts.
Choose Single Theme or explicitly include it in a custom rotation or schedule.
